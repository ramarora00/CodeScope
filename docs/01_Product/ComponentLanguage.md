# Component Language Dictionary

This document serves as the permanent product vocabulary source of truth across CodeScope. It dictates the naming conventions used in UI copy, code comments, documentation, and future components to ensure a calm, professional, and enterprise-grade user experience.

| Avoid (Technical/Legacy) | Use (Product) |
| :--- | :--- |
| Investigation | Analysis |
| Upload | Connect Repository |
| Overview | Repository Health |
| Mission Control | CodeScope Home |
| Sidebar | Navigation Rail |
| Workspace | Analysis Session |
| Loading | Preparing Repository |
| Complete | Repository Ready |
| Delete | Remove |
| Graph | Knowledge Graph |

*Note: Internal engineering terminology (e.g., FSD feature folders like `repository/`) may differ slightly from the UI naming (`Repository Connection`) as long as they follow the established Migration roadmap. However, UI components, text, and user-facing copy MUST strictly adhere to this dictionary.*
